## Question

What should the artist landing page template look and behave like?

Build a rough prototype of the artist page covering all 8 sections:
1. **Hero** — artist photo + name, headline
2. **Portfolio/gallery** — grid of tattoo work photos
3. **About/bio** — artist story, specialty, experience
4. **Booking CTA** — WhatsApp button/link as the primary conversion
5. **Testimonials** — client reviews
6. **Instagram feed** — embedded feed or gallery
7. **FAQ** — accordion or list of common questions
8. **Studio location** — address, embedded map

The prototype should be a single HTML file using the vaif-lp design system (CSS variables, fonts, gold accent) and mobile-first responsive layout. It doesn't need to be wired to real data — hardcoded placeholder content is fine. The goal is to have something concrete to react to before writing the spec.

Link the prototype as an asset on this ticket when done.
