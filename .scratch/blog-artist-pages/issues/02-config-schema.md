## Question

What should the artist config file schema be?

Each artist gets a config file that drives their landing page. The page has 8 sections: hero, portfolio, about, booking CTA (WhatsApp), testimonials, Instagram feed, FAQ, location. The schema must cover all data needed to render every section.

What fields, types, and structure?
- Which fields are required vs optional?
- How are images referenced (portfolio grid, hero photo)?
- How are testimonials structured (text, name, photo)?
- How is the FAQ structured (question/answer pairs)?
- What identifies the artist (slug, display name, Instagram handle)?
- Should the config be PHP (array return), JSON, or YAML?
- What's the WhatsApp number/CTA configuration?
