# VAIF

Brazilian marketing agency for tattoo artists. Products: ads management, CRM, SDR agent.

## Repo layout

```
packages/   — runnable products
  crm/      — future CRM application
  flows/    — n8n workflow JSON exports
  infra/    — WAHA, n8n, Coolify infrastructure config
  lp/       — landing page (vaif.com.br)
design/     — contracts, ADRs, spec documents
docs/       — agent tooling (issue-tracker, domain, triage-labels)
.scratch/   — wayfinding maps, tickets, research
```
